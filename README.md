# 🇮🇳 Government Project Tracker (Hybrid Blockchain)

A hybrid blockchain system using **Hyperledger Fabric**, **Polygon**, and **IPFS** to track and verify Indian government infrastructure projects with full transparency and decentralization.

---

## 🚀 Technologies Used

- **Hyperledger Fabric** – For private permissioned blockchain (project metadata, smart contracts)
- **Polygon (Ethereum)** – For public project verification (hashes, milestones)
- **IPFS** – For decentralized document storage (PDFs, reports)
- **Node.js / Python** – Backend APIs and service layer
- **React.js** – Admin and public frontend dashboard
